# Заявки на автопилоте в Google Таблице

Та же система, что и в основном проекте, только работает внутри Google Таблицы: сервер не нужен, это бесплатно. Таблица хранит заявки, Google выдаёт ссылку на форму и адрес вебхука, уведомления приходят в Telegram.

Настройка занимает около 15 минут.

## 1. Telegram-бот (3 минуты)

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя и адрес бота, который заканчивается на `bot`.
2. Скопируйте токен вида `123456789:AAE...`.
3. Откройте своего нового бота и отправьте ему любое сообщение, например «привет». Без этого бот не сможет вам писать.

## 2. Таблица и код (5 минут)

1. Создайте новую Google Таблицу: [sheets.new](https://sheets.new).
2. Меню **Расширения → Apps Script**.
3. Удалите всё в файле `Код.gs` и вставьте содержимое [`Code.gs`](Code.gs).
4. Слева нажмите **+** рядом с «Файлы» → **HTML** → назовите `Form` (без `.html`) → вставьте содержимое [`Form.html`](Form.html).
5. Нажмите **Сохранить** (значок дискеты).

## 3. Настройка (3 минуты)

1. Вернитесь на вкладку с таблицей и обновите страницу. Через несколько секунд появится меню **Заявки**.
2. **Заявки → 1. Подключить Telegram**. Google попросит разрешение:
   «Продолжить» → выберите аккаунт → «Дополнительные настройки» → «Перейти на страницу проекта» → «Разрешить».
   Это ваш собственный скрипт, поэтому Google показывает предупреждение.
3. Снова **Заявки → 1. Подключить Telegram** → вставьте токен. Бот пришлёт «✅ Бот подключён».
4. **Заявки → 3. Отправить тестовую заявку**. В таблице появится строка, а в Telegram — уведомление.

Claude подключать необязательно: без него заявки разбираются по ключевым словам. Чтобы подключить, возьмите ключ на [console.anthropic.com](https://console.anthropic.com) и выберите **Заявки → 2. Подключить Claude**. Разбор 1000 заявок стоит примерно $0,30.

## 4. Ссылка на форму и вебхук (3 минуты)

1. В редакторе Apps Script: **Начать развертывание → Новое развертывание**.
2. Шестерёнка → **Веб-приложение**.
3. «Запуск от имени»: **Я**. «У кого есть доступ»: **Все**.
4. **Начать развертывание** → скопируйте адрес веб-приложения (заканчивается на `/exec`).

Откройте этот адрес в браузере: там форма заявки. Отправьте заявку с телефона, она придёт в Telegram и появится в таблице.

## Подключение к сайту

Адрес `/exec` — это и есть вебхук.

- **Tilda:** Настройки сайта → Формы → Webhook → вставьте адрес → в настройках блока формы включите этот вебхук.
- **WordPress:** Contact Form 7 или Elementor Forms → действие «Webhook» → вставьте адрес.

Чтобы чужие не отправляли мусор на ваш адрес, выберите **Заявки → Защитить вебхук ключом** и добавьте к адресу для сайта `?key=...`. Форма по самому адресу продолжит работать без ключа.

## Если что-то не работает

- **Нет меню «Заявки».** Обновите страницу таблицы и подождите 5–10 секунд.
- **«Не нашёл переписку с ботом».** Напишите боту любое сообщение и повторите пункт 1.
- **Изменили код, а работает по-старому.** Начать развертывание → Управление развертываниями → карандаш → Версия: «Новая версия» → Развернуть. Адрес при этом не меняется.
- **Ошибки.** В редакторе Apps Script слева откройте «Выполнения»: там видно, что пошло не так.
