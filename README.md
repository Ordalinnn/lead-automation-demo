# Заявки с сайта → ИИ-разбор → Google Sheets → Telegram

**Живое демо и видео:** https://ordalinnn.github.io/zayavki/

Демо-проект для портфолио. Клиент оставляет заявку на сайте, а дальше всё происходит само:

1. **Claude разбирает заявку**: категория (покупка, консультация, поддержка, спам), приоритет, суть в одном предложении и черновик ответа.
2. **Заявка попадает в Google Таблицу**, одна строка на заявку.
3. **Менеджеру приходит сообщение в Telegram**: срочные помечены 🔴, спам не беспокоит.

Что сделано для надёжности:
- Заявка не теряется. Если Claude недоступен, работают правила по ключевым словам. Если недоступен Google Sheets, заявка пишется в CSV.
- Защита от ботов без капчи: скрытое поле-ловушка.
- Проверка ввода: нужен телефон или email.
- Тесты на основные сценарии.

## Запуск за минуту (демо-режим, без ключей)

```bash
pip install -r requirements.txt
uvicorn app:app --reload
```

Откройте http://localhost:8000, отправьте заявку. Она появится в `data/leads.csv`, а текст Telegram-сообщения будет в консоли.

Проверка: `pytest -q`. Статус подключений: http://localhost:8000/health.

## Подключение настоящих сервисов

Скопируйте `.env.example` в `.env`, заполните нужное и запустите с `uvicorn app:app --env-file .env`. Каждый сервис включается отдельно.

**Claude**
- Ключ: https://console.anthropic.com → API Keys → `ANTHROPIC_API_KEY`.
- Модель по умолчанию `claude-haiku-5-5`: быстрая и дешёвая, для сортировки заявок её хватает. Для сложных случаев можно указать `CLAUDE_MODEL=claude-sonnet-5-5` или `claude-opus-5-5`.

**Google Sheets**
1. Google Cloud Console → создать проект → включить Google Sheets API и Google Drive API.
2. IAM → Service Accounts → создать → Keys → Add key → JSON. Сохранить как `service-account.json`.
3. Открыть таблицу → «Настройки доступа» → добавить email сервисного аккаунта с правом редактора.
4. `GOOGLE_SHEET_ID` — часть адреса таблицы между `/d/` и `/edit`.

**Telegram**
1. Написать @BotFather → `/newbot` → получить токен → `TELEGRAM_BOT_TOKEN`.
2. Написать боту любое сообщение (или добавить его в группу менеджеров).
3. Открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, взять `chat.id` → `TELEGRAM_CHAT_ID`.

## Сколько это стоит клиенту

Разбор заявок оплачивается через Claude API по факту использования, отдельно от подписки Claude. Лучше, чтобы ключ был на аккаунте клиента: он регистрируется на console.anthropic.com, пополняет баланс (хватит $5) и передаёт ключ.

| Статья | Примерно в месяц |
|---|---|
| ИИ-разбор, Claude Haiku 5.5 | около $0,30 за 1000 заявок |
| ИИ-разбор, Claude Opus 5.5 | около $10–15 за 1000 заявок |
| Сервер (VPS или Render) | $0–5 |
| Telegram, Google Таблицы | бесплатно |

Оценка для заявки средней длины (около 400 токенов на входе и до 500 на выходе) по ценам Anthropic на октябрь 2026. Точный расход видно в консоли Anthropic в разделе Usage. Без ключа проект работает бесплатно: заявки сортируются по ключевым словам, но черновик ответа получается шаблонным.

## Подключение к сайту клиента

Для конструкторов сайтов есть адрес вебхука, который понимает любые названия полей:

```
https://ВАШ-СЕРВЕР/webhook?key=WEBHOOK_SECRET&source=tilda
```

Сервер отвечает сразу, а разбор заявки идёт в фоне, поэтому конструктор не ждёт ответа от ИИ. Имя, телефон, email и текст распознаются автоматически, а остальные поля (услуга, филиал, дата) дописываются в текст заявки.

**Tilda.** Настройки сайта → Формы → Webhook → вставить адрес вебхука → в блоке формы включить этот сервис. Tilda проверит адрес тестовым запросом, сервер ответит `ok`.

**WordPress.** Contact Form 7 или Elementor Forms: в настройках формы добавить действие «Webhook» и указать адрес вебхука. Поля `your-name`, `your-phone`, `your-email`, `your-message` распознаются сами.

**Свой сайт или форма из `static/index.html`.** JSON на `/api/lead`:

```json
{"name": "Анна", "phone": "+7 701 000 00 00", "email": "", "message": "Сколько стоит доставка?", "source": "сайт"}
```

## Запуск на сервере

Подойдёт любой VPS за $5 в месяц (бесплатные тарифы Render и Railway засыпают, и первая заявка после паузы может прийти с задержкой).

```bash
docker build -t leads .
docker run -d --restart unless-stopped --env-file .env -p 8000:8000 -v $(pwd)/data:/app/data leads
```

Без Docker: `pip install -r requirements.txt` и `uvicorn app:app --host 0.0.0.0 --port 8000`. Для HTTPS поставьте перед сервером Caddy или nginx: конструкторы сайтов отправляют вебхуки только на `https://`.

## Структура

```
app.py               веб-сервер, форма и вебхук
leads/webhook.py     распознавание полей Tilda, WordPress и других форм
leads/classifier.py  разбор заявки (Claude или правила)
leads/storage.py     Google Sheets / CSV
leads/notifier.py    Telegram
leads/models.py      поля заявки и результата разбора
leads/config.py      настройки из переменных окружения
static/index.html    форма заявки
tests/               тесты
```

## Как показывать клиенту

Запишите видео на 1–2 минуты: заполняете форму → через пару секунд строка в таблице → сообщение в Telegram с приоритетом и черновиком ответа. В описании услуги:

> Настрою приём заявок с вашего сайта: каждая заявка сразу появится в Google Таблице, а менеджер получит уведомление в Telegram. ИИ отметит срочные заявки, отсеет спам и подготовит черновик ответа. Срок: 1–2 дня.
