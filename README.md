# Заявки с сайта → ИИ-разбор → Google Sheets → Telegram

Демо-проект для портфолио. Клиент оставляет заявку на сайте, а дальше всё происходит само:

1. **Claude разбирает заявку**: категория (покупка, консультация, поддержка, спам), приоритет, суть в одном предложении и черновик ответа.
2. **Заявка попадает в Google Таблицу**, одна строка на заявку.
3. **Менеджеру приходит сообщение в Telegram**: срочные помечены 🔴, спам не беспокоит.

Что сделано для надёжности:
- Заявка не теряется. Если Claude недоступен, работают правила по ключевым словам. Если недоступен Google Sheets, заявка пишется в CSV.
- Защита от ботов без капчи: скрытое поле-ловушка.
- Проверка ввода: нужен телефон или email.
- Тесты на основные сценарии.

## Запуск за минуту (демо-режим, без ключей)

```bash
pip install -r requirements.txt
uvicorn app:app --reload
```

Откройте http://localhost:8000, отправьте заявку. Она появится в `data/leads.csv`, а текст Telegram-сообщения будет в консоли.

Проверка: `pytest -q`. Статус подключений: http://localhost:8000/health.

## Подключение настоящих сервисов

Скопируйте `.env.example` в `.env`, заполните нужное и запустите с `uvicorn app:app --env-file .env`. Каждый сервис включается отдельно.

**Claude**
- Ключ: https://console.anthropic.com → API Keys → `ANTHROPIC_API_KEY`.
- Модель по умолчанию `claude-opus-5-5`. Для большого потока заявок можно поставить дешёвую `CLAUDE_MODEL=claude-haiku-5-5`.

**Google Sheets**
1. Google Cloud Console → создать проект → включить Google Sheets API и Google Drive API.
2. IAM → Service Accounts → создать → Keys → Add key → JSON. Сохранить как `service-account.json`.
3. Открыть таблицу → «Настройки доступа» → добавить email сервисного аккаунта с правом редактора.
4. `GOOGLE_SHEET_ID` — часть адреса таблицы между `/d/` и `/edit`.

**Telegram**
1. Написать @BotFather → `/newbot` → получить токен → `TELEGRAM_BOT_TOKEN`.
2. Написать боту любое сообщение (или добавить его в группу менеджеров).
3. Открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, взять `chat.id` → `TELEGRAM_CHAT_ID`.

## Подключение к сайту клиента

Сайт отправляет POST на `/api/lead`:

```json
{"name": "Анна", "phone": "+7 900 000-00-00", "email": "", "message": "Сколько стоит доставка?", "source": "tilda"}
```

Подходит для Tilda (вебхук формы), WordPress (Contact Form 7 + webhook), любого своего сайта или готовой формы из `static/index.html`.

Хостинг: любой VPS за $5/мес или Render/Railway. Команда запуска: `uvicorn app:app --host 0.0.0.0 --port 8000`.

## Структура

```
app.py               веб-сервер и форма
leads/classifier.py  разбор заявки (Claude или правила)
leads/storage.py     Google Sheets / CSV
leads/notifier.py    Telegram
leads/models.py      поля заявки и результата разбора
leads/config.py      настройки из переменных окружения
static/index.html    форма заявки
tests/               тесты
```

## Как показывать клиенту

Запишите видео на 1–2 минуты: заполняете форму → через пару секунд строка в таблице → сообщение в Telegram с приоритетом и черновиком ответа. В описании услуги:

> Настрою приём заявок с вашего сайта: каждая заявка сразу появится в Google Таблице, а менеджер получит уведомление в Telegram. ИИ отметит срочные заявки, отсеет спам и подготовит черновик ответа. Срок: 1–2 дня.
